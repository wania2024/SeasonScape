# 🌍 SeasonScape
### AI-Powered Environment & Place Recommendation System

SeasonScape helps you discover the perfect place in Pakistan based on your mood, 
budget, temperature preference, crowd level, and environment type — powered by AI.

---

## 🚀 Features
- Personalised place recommendations using heuristic-based scoring
- A*-inspired search logic for intelligent ranking
- Google Gemini AI generates conversational comparisons between top matches
- Multi-step interactive form with animated transitions
- Responsive design across all screen sizes

---

## 🛠️ Tech Stack
| Layer | Technology |
|-------|-----------|
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, Flask |
| AI | Google Gemini API |
| Algorithm | Heuristic Scoring + A* Search Logic |

---

## ⚙️ How to Run Locally

1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Create a .env file in the root folder:
   GOOGLE_API_KEY=your_gemini_api_key_here
4. Run the app:
   python app.py
5. Open your browser at http://localhost:5000
